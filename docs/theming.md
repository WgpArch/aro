# Theming Guide

## Color Configuration
Colors are defined in `~/.config/aro/config` using hex format: `0xRRGGBBAA`.

### Current Theme
```ini
background = 0x0c0f13ff     # Dark blue-gray
frame_focus = 0x161b23ff    # Focused frame
accent = 0xe6a54bff         # Amber/gold
text = 0xd7dfe9ff           # Primary text
bar_color = 0x0a0d11ff      # Bar background

Wallpaper
wallpaper = ~/Pictures/ALNW/Pianist.jpg
Or use the built-in picker: mod+w

Effects & Animations
radius = 5                  # Rounded corners
gaps = 9                    # Between tiled windows
anim_ms = 340               # Standard window animations
workspace_slide_ms = 220    # Workspace transitions
