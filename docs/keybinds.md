# Keybinds Reference

## Basic Controls
| Keybind | Action |
|---------|--------|
| `mod+Return` | Launch terminal |
| `mod+d` | Launch app launcher (fuzzel) |
| `mod+q` | Close focused window |
| `mod+shift+e` | Quit compositor (with confirmation) |
| `mod+space` | Toggle floating |
| `mod+f` | Toggle fullscreen |
| `Print` | Take full-screen screenshot |

## Window Navigation
| Keybind | Action |
|---------|--------|
| `mod+hjkl` | Move focus (left, down, up, right) |
| `mod+shift+hjkl` | Move window |
| `mod+ctrl+hjkl` | Resize window |
| `mod+Tab` / `mod+shift+Tab` | Window switcher (next/prev) |

## Workspaces (1-12)
| Keybind | Action |
|---------|--------|
| `mod+1` to `mod+9` | Switch to workspace 1-9 |
| `mod+0` | Switch to workspace 10 |
| `mod+F1` / `mod+F2` | Switch to workspace 11 / 12 |
| `mod+shift+1` to `mod+shift+F2` | Send window to workspace |

## Layouts & Special Features
| Keybind | Action |
|---------|--------|
| `mod+t` | Cycle layout (manual/dwindle/monocle/scroll) |
| `mod+v` / `mod+s` | Split right / Split down |
| `mod+o` | Overview mode |
| `mod+w` | Wallpaper picker |
| `mod+minus` | Show/hide scratchpad |
