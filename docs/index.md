# Welcome to Aro Compositor Documentation

Aro is a minimal, flat, spring-animated tiling window manager for Wayland, built on wlroots 0.20.

## What Makes Aro Special
- **Live Configuration:** Save the config file and changes apply instantly.
- **Multiple Layouts:** Manual (i3-style), Dwindle (Hyprland-style), Monocle, and Scroll.
- **Spatial Focus:** Navigate windows based on their actual screen position.
- **Built-in Tools:** Wallpaper picker, bar, and window switcher.
- **SceneFX Support:** Rounded corners, blur effects, and glass headers.
